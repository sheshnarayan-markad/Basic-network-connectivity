# Basic-network-connectivity
Basic WAN network

Basic Network Connectivity Project
Project Overview

This project demonstrates a basic computer network created using Cisco Packet Tracer.

The main objective of this project is to understand how network devices are connected and how basic communication takes place between devices in a network.

This is my first networking project, created as part of my learning journey in Computer Networking and Cybersecurity.

Project Objective

The objectives of this project are:

Understand basic network topology
Connect network devices correctly
Configure IP addresses
Establish communication between devices
Understand the role of switches and routers
Test network connectivity using the ping command

Technologies and Tools Used
Cisco Packet Tracer
Ethernet Networking
IPv4 Addressing
Basic Routing
Network Switches
Routers

Project File

The Cisco Packet Tracer project file is available in this repository:

first_1project.pkt

Open the file using Cisco Packet Tracer to view and test the complete network topology.
